# wxWidgets Implementation

wxWidgets implementation of the cross-platform sticky-notes application used in the framework comparison.

## Status

**Development pending.**

The implementation will reproduce the core functionality already completed in the Qt version to provide a direct practical comparison between the two frameworks.

The planned baseline includes:

- frameless independent sticky-note windows;
- direct text editing;
- note dragging;
- multiple simultaneous notes;
- deletion;
- resizing;
- persistent text, position, dimensions, and colors;
- random pastel palettes;
- readable contrasting text colors;
- a compact paper-stack launcher;
- click-to-create and drag-to-create interaction.

Development will use C++20 and CMake, with wxWidgets integrated into the existing project structure.
